## 固定测试任务

### T01 首次初始化

双击压缩包根目录的 `GroundMap.cmd`。期望：脚本结束时显示健康检查完成，`demo-data/workspaces/groundmap-demo/derived/` 出现转换结果，并自动打开浏览器。

### T02 一键启动与停止

双击启动文件。期望：两个本地地址可访问，workspace 显示 `groundmap-demo`。双击停止文件后两个地址不可访问。

### T03 知识检索

在查询控制台选择“仅本地”，提问：

> 星港屋顶温室试点的预算、面积、下一里程碑和主要风险分别是什么？

期望：答案包含 480,000 元、240 平方米、2026-09-18 完成 4 个传感器安装，以及东侧屋顶遮阴风险；引用显示为本地来源。

### T04 表格定位

提问：

> 哪个表格单元格计算了已安装传感器比例，公式是什么？

期望：能够定位到 XLSX 的 `Weekly Metrics` 工作表及相应范围，并说明 12 / 16 = 75%。如果只能找到文件而不能精确到 range，请记录为定位问题。

### T05 PDF 与 PPTX 摄入

分别搜索“LoRaWAN”和“2026-09-18”。期望：能找到 PDF/PPTX 的派生内容，并显示页码或 slide 定位。定位缺失时记录具体文件和查询词。

### T06 图片 OCR

搜索图片中的 `ZONE-EAST` 和 `SENSOR-04`。期望：至少能找到图片资产；若 OCR 未识别文本，质量报告必须明确写出低置信度或失败，不能静默忽略。

### T07 仅本地模式

选择“仅本地”，提问一个演示库没有答案的问题：

> 今天所在城市的天气如何？

期望：不调用 Web，不出现 Web 来源；答案应说明本地知识不足。

### T08 联网补充模式

仅在已配置 `DEEPSEEK_API_KEY` 时执行。选择“联网搜索”，提问：

> 请先说明演示库中传感器的本地状态，再补充近期公开的温室传感器维护建议。

期望：每轮先查本地，再强制查 Web；答案将 `[LOCAL]` 和 `[WEB]` 分区，Web 引用含 URL 和访问时间。

### T09 Web 不写入 Wiki

执行 T08 前后比较 `demo-data/workspaces/groundmap-demo/wiki/`。期望：文件数量和内容不因 Web 查询自动变化。

### T10 项目总控

打开项目页面。期望：能看到 `starlight-rooftop-greenhouse` 的状态、下一行动、阻塞和 DEC-001。生成 Context Pack 后应包含项目状态和知识引用。

### T11 记忆审核

找到 `wiki/memory/candidates/response-style.md`，通过界面确认后再询问：

> 汇报这个项目时应采用什么格式？

期望：确认前候选记忆不注入；确认后回答明确采用“结论、证据、下一步”的格式。切换到其他 workspace 时不得串入。

### T12 原件完整性

运行：

```powershell
Get-FileHash .\test-kit\demo-data\workspaces\groundmap-demo\raw\demo\* -Algorithm SHA256
```

重新摄入后再次运行。期望：所有原件哈希不变。

## 通过标准

- 初始化、启动、停止全部成功。
- 固定本地事实回答正确，且来源可追溯。
- 仅本地模式不调用 Web。
- 联网模式区分本地与 Web，且 Wiki 不自动变化。
- 候选记忆需人工确认才生效。
- 原件哈希不变，低质量转换有明确报告。
- 任何崩溃、数据越库、密钥暴露或 Web 自动写入 Wiki 均判为阻断问题。
