# GroundMap 代码快照说明（2026-09-11）

本快照保存“规模化摄取流程”改造之前的可运行版本，便于后续对比和回退。

## 已包含能力

- 多模态文件转换、稳定 anchor、质量报告和摄取成本估算。
- 统一证据查看器：Markdown 证据、原始图片、PDF、音频时间点及 sidecar locator。
- 项目总控：状态、决策、执行记录、Context Pack 和版本化成果。
- 查询工作台：当前会话自动恢复、历史会话列表、单条回答与完整会话 Markdown 下载。
- Local / Hybrid 查询边界、Provider 运行指标和 Codex/DeepSeek 等模型接入。
- Windows 单机测试包、启动脚本和公开合成测试说明。

## 安全边界

- 私人知识库通过 `KB_ROOT` 接入，不包含在本仓库或本快照中。
- `raw/`、`derived/` 运行产物、`.env`、API Key、构建目录和测试日志不进入版本。
- GroundMap 核心不调用 LLM；模型路由只存在于独立的 `tools/debug-console/` 客户端。
